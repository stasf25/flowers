# Сравнение цен — границы титульных витрин (Москва, зафиксировано 2026-10-03)

Подход: вместо несопоставимых позиций по конкретным букетам фиксируем нижнюю и верхнюю границы цен букетов с титульных страниц. Данные заданы пользователем.

| Магазин | Сайт | Нижняя граница, руб | Верхняя граница, руб | Ширина диапазона | Комментарий |
|---|---|---|---|---|---|
| Flor2u | https://flor2u.ru | 2500 | 8000 | 5500 | Самый доступный вход, масс-маркет |
| Флорист.ру | https://www.florist.ru | 3000 | 21500 | 18500 | Самый широкий диапазон, есть премиум |
| Русский букет | https://rus-buket.ru | 3000 | 18000 | 15000 | Масс + шик (101 роза Бриллиант) |
| ВеснаFlowers | https://vesnaflowers.ru | 6000 | 18000 | 12000 | Самый высокий вход, авторские, вне гонки количества |

## Выводы для сопоставления
- Вход: Flor2u 2500 < Флорист/Рус.букет 3000 < Весна 6000 (x2.4 к минимуму).
- Потолок: Flor2u 8000 < Рус/Весна 18000 < Флорист 21500.
- Весна — премиальный авторский сегмент, не конкурирует по 21/51 розе.
- Flor2u — ценовой лидер низа, Флорист — лидер ширины/премиума.
